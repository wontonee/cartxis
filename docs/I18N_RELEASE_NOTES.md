# i18n release notes (draft)

## Multi-language storefront

Cartxis now includes first-class internationalization:

- **15+ languages** covering the Middle East, Europe, and Africa
- **RTL** for Arabic, Hebrew, and Persian
- Storefront **language switcher** + locale-aware currency formatting
- **Product & category translations** in admin
- Mobile/API support via `GET /api/v1/locales` and `Accept-Language` / `X-Locale`

### Screenshot guidance

Capture the default theme homepage after visiting `/locale/ar` (RTL header + Arabic chrome) for the GitHub release and README.
